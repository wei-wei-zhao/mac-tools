# WiFiDrop · macOS 局域网互传

手机浏览器打开网页，和 Mac 双向传文件、同步文字。**零安装、零登录、纯局域网**。

## 快速开始

**两种方式，任选其一：**

1. **双击 `启动.command`** —— 会弹出一个终端窗口，里面显示二维码（窗口保持开着服务才在跑）
2. **手输地址** —— 手机浏览器打开 `http://<Mac的IP>:8765`

手机连**同一个 WiFi** 即可。不知道自己 IP 时，双击 `显示二维码.command` 会在终端里告诉你怎么打开。

> ⚠️ 注意：`启动.command` 双击后如果**没弹窗口**，说明系统拦了脚本执行。右键点它 → 选「打开」→ 在弹窗里再点「打开」即可放行。或者打开 Terminal，输入：
> ```
> cd ~/Downloads/WiFiDrop && ./启动.command
> ```

## 三个功能

| 页面 | 功能 | 说明 |
|---|---|---|
| 📤 传到 Mac | 手机 → 电脑 | 点选或多选文件，带进度条 |
| 📥 从 Mac 取 | 电脑 → 手机 | **文件列表 + 预览**，可逐层浏览任意目录 |
| 📋 文字 | 剪贴板双向 | 「发到 Mac」写入 Mac 剪贴板（⌘V 可用）；「取 Mac 剪贴板」拉到手机 |

## 📄 文件列表（可预览）

「从 Mac 取」页现在是个真正的文件浏览器：

- **逐层浏览** —— `↑` 返回上级，点文件夹进入，能逛遍你主目录下任何位置
- **快捷入口** —— 接收目录 / 桌面 / 下载 / 图片 一键跳转
- **显示传入时间** —— 每个文件都有 `🕐 2026-10-28 11:45` 精确到分钟，24 小时内带绿色「新」标记
- **三种排序** —— 最新 / 名称 / 大小
- **图片缩略图** —— 图片直接显示缩略图，不用点开就知道是什么
- **列表末尾有「到底了」提示**，底部内边距会按导航栏实际高度自动计算，最后一项不会被挡

## 🌐 网络模式

WiFiDrop 本来就是**走局域网直连**：手机和 Mac 在同一个网络里直接传，不经过任何服务器、不上公网。

应用会自动识别当前网络，告诉你手机能不能连上：

| 网络类型 | 判定依据 | 提示 |
|---|---|---|
| 🏠 家庭/普通 WiFi | `192.168.x.x` / `172.x` | ✅ 通畅，手机连同一个即可 |
| 📶 手机热点 | `172.20.10.x`（iPhone）、`192.168.43.x`（安卓） | ✅ 通畅，直连一定能通 |
| 🏢 企业/校园网络 | `10.x.x.x` | ⚠️ 可能受限，这类网络常开设备隔离 |
| 🔌 未联网 | 无 IP | ❌ 请先联网 |

**手机上**：上传页顶部有网络状态卡片，带颜色标识（绿=通畅 / 橙=可能受限 / 红=异常），点 `⟳` 可重新检测。

**Mac 上**：菜单 ⚡ →「网络检测 / 用热点连接…」，会告诉你当前网络和该怎么做。

### 连不上怎么办？用热点

公司/学校网络常有**设备隔离**（同一个 WiFi 下设备之间不能互相访问），这时：

1. 手机上打开「个人热点」
2. Mac 点右上角 WiFi 图标，连你的热点
3. 回到菜单 ⚡ →「显示二维码」，重新扫码

热点下手机和 Mac 是直连的，一定能通。

> 关于蓝牙：真正的蓝牙文件传输在 macOS 上受限严重（系统不让程序直接配对传文件），且速度只有几十 KB/s，比拍照还慢，所以没做。局域网 + 热点已经覆盖所有场景。

## 👥 连接设备

页面右上角有个绿色徽标，显示当前**在线设备数**，点它看详情：

- 每台设备的**系统**（iPhone / iPad / 安卓 / 鸿蒙 / Mac / Windows）
- **浏览器**（Safari / Chrome / 微信 / 钉钉 / 飞书 / 华为浏览器…）
- **IP 地址**、首次连接时间、请求次数
- **在线 / 离线**状态（2 分钟内有操作算在线），离线显示「几分钟前」

面板里还能「清理离线记录」。设备列表每 5 秒自动刷新。

> 说明：设备识别基于 IP + User-Agent 指纹。同一 WiFi 下同型号、同浏览器的两台手机可能被合并成一条，日常用足够。

**预览支持：**

| 类型 | 格式 | 方式 |
|---|---|---|
| 图片 | jpg png gif webp heic bmp avif | 全屏查看，可双指缩放 |
| 视频 | mp4 mov m4v webm | 内嵌播放器，支持拖动进度条 |
| 音频 | mp3 m4a wav aac flac | 内嵌播放 |
| 文本 | txt md csv json log 代码 | 直接渲染内容 |
| 其他 | docx xlsx zip pdf 等 | 提示下载（手机系统可自行打开） |

点文件行 = 预览；点 `⬇` = 下载。预览里右上角也能直接下载。

## 📁 保存位置（可随时切换）

「传到 Mac」页顶部就是**保存位置**，点「切换」随时改，不用回电脑操作。

**三种切换方式：**

| 方式 | 说明 |
|---|---|
| 常用位置 | 一键选 WiFiDrop / 下载 / 桌面 / 图片 / 文稿 / 影片 |
| 浏览文件夹 | 像文件管理器一样逐层进入，点「用这个文件夹」确认；**可直接「＋ 新建文件夹」** |
| 手动输入 | 写 `~/Desktop/收图` 这种路径，不存在会自动创建 |

**新建文件夹**：在「浏览文件夹」页点 `＋ 新建文件夹`，输入名字回车即可，
建完自动刷新列表并高亮显示「刚创建」。名字重复会提示，不会覆盖已有文件夹。

**选择会被记住** —— 写在 `wifidrop/.wifidrop.json`，下次启动自动恢复。

**自动分类开关**（也在保存位置卡片里）：
- 关闭（默认）：所有文件直接放在选定目录
- 开启：按类型自动分到 `图片/`、`视频/`、`其他/` 子目录

**安全边界**：只能选你自己主目录（`~`）下的文件夹，指向 `/etc`、`/tmp` 这类系统路径会被拒绝。目录必须可写，指向文件而非文件夹也会被拒绝。

## 命令行参数

```bash
./启动.command --port 9000              # 换端口
./启动.command --dir ~/Desktop          # 指定接收目录（覆盖已保存的选择）
./启动.command --reset                  # 重置为默认目录
```

## 兼容性

iOS Safari / 安卓 Chrome / 鸿蒙浏览器都支持，也能「添加到主屏幕」当 App 用。

## 安全说明

- 只监听局域网，**不开公网**，不做任何外部上报
- 文件名经过清洗，拒绝路径穿越（`../`）
- 同名文件自动加序号 `(1)`，不覆盖已有文件
- 单文件上限 4GB
- 注意：同一 WiFi 下的其他人知道地址也能访问，在公共 WiFi 用完请及时 Ctrl+C 关闭

## 文件结构

```
wifidrop/
├── server.py              # Flask 服务端
├── templates/
│   └── index.html         # 手机端页面（单文件，无外部依赖）
├── .wifidrop.json         # 记住你选的保存位置和分类开关（自动生成，不入库）

```
