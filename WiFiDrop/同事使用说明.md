# WiFiDrop 使用说明（给同事）

手机和 Mac 之间快速传文件、图片、文字，不用微信、不用数据线。

---

## 一、安装

1. 拿到 **`WiFiDrop.app`**（或压缩包，解压得到它）
2. 拖进 **「应用程序」文件夹**
3. **第一次打开**：右键点 `WiFiDrop` → 选「打开」→ 弹窗里再点「打开」

> 为什么要右键？因为这是个人开发的小工具，没有 Apple 开发者签名。右键打开一次之后，以后双击就行。

**看到菜单栏出现 ⚡ 图标 = 启动成功。**

---

## 二、使用

### Mac 上

点菜单栏 ⚡ 图标，有这些选项：

| 菜单项 | 作用 |
|---|---|
| **📱 显示二维码（手机扫我）** | **弹出二维码窗口，手机直接扫** |
| 打开上传页面 | 在浏览器打开，看当前地址 |
| 查看访问地址 | 弹窗显示手机该访问的网址 |
| 在 Finder 打开接收目录 | 看收到了哪些文件 |
| 更换保存位置… | 选一个新的文件夹存手机传来的文件 |
| 复制地址 | 把网址复制到剪贴板，方便发到群里 |
| 重启服务 | 出问题时点一下 |
| 检查更新 / 更新设置… | 版本相关 |
| 退出 WiFiDrop | 关闭 |

**最常用的就是第一个**：点「显示二维码」，屏幕上会出现一个带二维码的小窗口，手机扫一下就连上了。

二维码窗口里还有两个按钮：
- **复制地址** —— 把网址复制到剪贴板
- **刷新地址** —— 换了 WiFi、IP 变了之后，点一下重新检测

### 手机上

1. 手机连**和 Mac 同一个 WiFi**
2. **Mac 上点菜单栏 ⚡ → 「📱 显示二维码（手机扫我）」**
3. 用手机相机 / 扫一扫扫那个二维码，自动打开网页
4. 三个页面：

| 页面 | 能干什么 |
|---|---|
| 📤 传到 Mac | 选文件传到电脑，可多选、有进度条 |
| 📥 从 Mac 取 | 浏览电脑上的文件、看图片/视频/文档、下载 |
| 📋 文字 | 手机输入文字 → Mac 上 ⌘V 直接粘贴；反过来也行 |

页面右上角有个绿色徽标显示**当前几台设备在线**，点它能看到每台设备是什么手机、什么浏览器、IP 和在线状态。

手机页面可以「添加到主屏幕」，以后像 App 一样点开。

## 三、常见问题

**Q：手机打不开页面？**
先看手机页面顶部的**网络状态卡片**：

| 卡片颜色 | 含义 | 怎么办 |
|---|---|---|
| 🟢 绿色 | 网络通畅 | 正常用 |
| 🟠 橙色 | 当前是企业网，可能隔离设备 | 改用手机热点（见下） |
| 🔴 红色 | Mac 没联网 | 先连 WiFi 或开热点 |

改成手机热点：
1. 手机打开「个人热点」
2. Mac 连你的热点
3. Mac 菜单 ⚡ →「显示二维码」，重新扫码

热点下手机和 Mac 直连，一定能通。

**Q：为什么不做蓝牙传输？**
蓝牙传文件在 macOS 上受限严重（系统不允许程序直接传文件），速度只有几十 KB/s，比拍照还慢。局域网和热点已经覆盖所有场景，更快更稳。

**Q：文件传哪去了？**
默认在 `~/Downloads/WiFiDrop`。手机上「📥 从 Mac 取」也能看到。

**Q：想换保存位置？**
手机上传页顶部点「切换」，或在 Mac 菜单里选「更换保存位置…」。

**Q：想新建一个文件夹来存？**
手机上传页点「切换」→「浏览文件夹」→ 点 `＋ 新建文件夹`，输入名字回车就行。
建完会自动出现在列表里，点它再点「用这个文件夹」就切过去了。

**Q：会不会把我的文件传给别人？**
不会。文件只在你的手机和你的 Mac 之间走**局域网**，不经过任何服务器、不上传公网。

**Q：别人能访问我的电脑吗？**
同一 WiFi 下知道地址的人能访问这个传输页面（只能传文件，不能操作电脑）。在咖啡厅、机场等公共 WiFi 用完建议退出 App。

**Q：菜单栏图标不见了？**
App 退出了。重新双击打开即可。

**Q：提示「无法验证开发者」？**
右键点 App → 打开 → 在弹窗里点「打开」。只需一次。

## 四、关于自动更新

如果管理员配好了更新地址，App 会：

- 每 6 小时自动检查一次新版本
- 有新版本时**在后台静默下载**
- **下次启动 App 时自动生效**（菜单栏图标会短暂显示 ⬆️）
- 万一新版本有问题，会自动回退到上一个版本

你也可以手动点菜单里的「检查更新」立即检查。

## 五、配置在哪

```
~/Library/Application Support/WiFiDrop/
├── config.json        # 更新地址等配置
└── update_state.json  # 更新状态
```

收到的文件在 `~/Downloads/WiFiDrop`（或你自定义的位置）。
