## 📦 WiFiDrop —— 手机和 Mac 之间快速传文件

不用微信传自己、不用数据线、不经过任何服务器。

**能干什么**
- 📤 手机照片/文件一键传到 Mac（有进度条）
- 📥 在手机上浏览 Mac 的文件，图片视频直接预览、看文档
- 📋 手机文字直接写进 Mac 剪贴板，Mac 上 ⌘V 就粘贴
- 📁 保存位置随时切换，还能新建文件夹
- 👥 能看到当前有几台设备连着

---

### 安装（30 秒）

**方式一：一键安装（推荐）**

1. 解压 zip
2. **双击 `安装 WiFiDrop.command`**
3. 如果提示"无法验证开发者" → **右键点它 → 选「打开」→ 再点「打开」**
4. 看到菜单栏出现 ⚡ 就好了

**方式二：手动安装**

1. 解压出 **`WiFiDrop.app`**，拖进 **「应用程序」** 文件夹
2. 打开 **「终端」** App，粘贴这行回车：
   ```
   xattr -cr /Applications/WiFiDrop.app
   ```
3. 右键点 `WiFiDrop` → 选「打开」→ 弹窗里再点「打开」

> 为什么要这么做？这是个人小工具，没有 Apple 开发者签名（证书 $99/年），
> 系统会默认拦住。清理一次隔离属性 + 右键放行，以后双击就行。

### 使用

**Mac 上**：点菜单栏 ⚡ → **「📱 显示二维码（手机扫我）」**

**手机上**：
1. 连和 Mac 同一个 WiFi
2. 扫那个二维码
3. 开用

三个页面：`📤 传到 Mac` / `📥 从 Mac 取` / `📋 文字`

---

### 手机打不开怎么办？

页面顶部有个网络状态卡片：

| 颜色 | 含义 | 做法 |
|---|---|---|
| 🟢 绿色 | 通畅 | 直接用 |
| 🟠 橙色 | 公司/学校网络，可能屏蔽设备互访 | 改用手机热点 ↓ |
| 🔴 红色 | Mac 没联网 | 先连 WiFi |

**改用手机热点**：
1. 手机打开「个人热点」
2. Mac 连你的热点
3. 菜单 ⚡ →「显示二维码」→ 重新扫码

热点下手机和 Mac 直连，一定能通。

### 常见问题

**Q：文件传到哪了？**
默认 `~/Downloads/WiFiDrop`。手机上「📥 从 Mac 取」也能看到。

**Q：会泄露我的文件吗？**
不会。文件只在你自己的手机和 Mac 之间走局域网，不上传任何服务器。

**Q：同事之间会互相看到吗？**
不会，每个人装的是独立的，只连自己的 Mac。

**Q：双击提示「无法打开，因为无法验证开发者」？**
右键点 `WiFiDrop.app`（或 `安装 WiFiDrop.command`）→ 选「打开」→ 弹窗里再点「打开」。

**Q：提示「已损坏，无法打开，应移到废纸篓」？**
这是误导，不是真损坏。打开「终端」，粘贴这行回车：
```
xattr -cr /Applications/WiFiDrop.app
```
然后再右键 → 打开。

**Q：双击完全没反应？**
大概率是权限问题。用「安装 WiFiDrop.command」那个脚本装，它会自动处理。

**Q：会不会自动更新？**
会。有新版本后台静默下载，下次启动自动生效，不用管。
