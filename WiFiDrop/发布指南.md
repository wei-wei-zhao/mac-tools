# WiFiDrop 发布与分发指南（给自己看）

## 一、当前产物

```
wifidrop/dist/
├── WiFiDrop.app                  ← 开发时直接双击测
└── release/
    ├── WiFiDrop-1.0.0.zip        ← 发给同事的就是这个（21MB）
    └── version.json              ← 自动更新用的版本清单
```

**zip 是给同事的**，解压出 `WiFiDrop.app`，拖进「应用程序」即可。

---

## 二、首次分发给同事

### 1. 把 zip 放到同事能下载的地方

需要**公网可访问**的地址，任选：
- 公司内网文件服务器
- 对象存储（腾讯云 COS / 阿里 OSS / 七牛）
- 你自己的服务器 + nginx
- 临时方案：发企业微信文件 / 网盘链接

### 2. 告诉同事怎么装

直接发 `同事使用说明.md` 的内容，重点是：
- 拖进「应用程序」
- **第一次右键 → 打开 → 再点打开**（绕过签名检查）

### 3. 配好更新地址（一次性）

把 `version.json` 和 `WiFiDrop-1.0.0.zip` 传到服务器**同一个目录**，例如：

```
https://your-server.com/wifidrop/
├── version.json
└── WiFiDrop-1.0.0.zip
```

然后每个同事在自己 Mac 上：
**菜单栏 ⚡ → 更新设置… → 粘贴 `https://your-server.com/wifidrop/version.json`**

> 如果嫌一个个配麻烦，可以把这个地址预置进代码（`updater.py` 的 `DEFAULT_CONFIG.update_url`），重新打包一版发下去，同事就免配置了。

## 三、发布新版本（以后每次）

```bash
cd wifidrop

# 一条命令：写版本号 → 打包 → 生成 zip 和 version.json
/Users/tal/.workbuddy/binaries/python/envs/default/bin/python release.py 1.1.0 \
  --base-url https://your-server.com/wifidrop/ \
  --notes "修复文件列表排序问题"
```

产出在 `dist/release/`：
- `WiFiDrop-1.1.0.zip`
- `version.json`（版本号已更新）

**把这两个文件覆盖到服务器**，同事的 App 会在 6 小时内自动检测到，
下次启动就变成新版。**你不用再发消息催任何人。**

## 四、自动更新怎么工作的

```
App 启动
  ↓
检查有没有上次下载好的包 → 有就替换（先备份当前版本）
  ↓
正常启动服务
  ↓
后台线程：每 6 小时查一次 version.json
  ↓
发现新版本 → 静默下载 → 校验 sha256 → 解压到 staging
  ↓
（不立即替换，避免动正在运行的进程）
  ↓
下次启动 App 时应用
```

### 回退保护

- 替换前先把当前版本完整备份到 `~/Library/Application Support/WiFiDrop/previous`
- 新版本启动后 30 秒内无异常才算「健康」
- 如果新版本启动就崩（没等到健康确认），下次启动自动回退到 `previous`

### 安全措施

| 措施 | 说明 |
|---|---|
| sha256 校验 | 下载的包和 version.json 里记录的不一致就拒绝安装 |
| 非压缩包检测 | 下回来是 HTML 错误页会识别并拒绝 |
| 原子替换 | 先下到 `.part` 再改名，不会装一半 |
| 主目录限制 | 保存位置只能选用户主目录内 |

## 五、常见问题

**Q：同事说「无法验证开发者」**
右键 → 打开 → 再点「打开」。一次性操作。

**Q：为什么包这么大（21MB）**
里面有完整的 Python 运行时和依赖，所以同事电脑**不需要装任何东西**。

**Q：同事是 Intel Mac 能用吗**
当前包是 **arm64（Apple Silicon）**。如果同事是 Intel Mac，需要用 Intel 的 Python 重新打一次包。
检查方法：同事点左上角苹果 → 关于本机 → 看芯片是「Apple M」还是「Intel」。

**Q：更新地址填错了怎么办**
重新点「更新设置…」改成正确的。填错了不影响正常使用，只是不会更新。

**Q：想关闭自动更新**
`~/Library/Application Support/WiFiDrop/config.json` 里把 `"auto_update"` 改成 `false`。

## 六、源码说明

| 文件 | 作用 |
|---|---|
| `server.py` | Flask 服务端，所有 API |
| `templates/index.html` | 手机端页面（单文件） |
| `app_main.py` | 菜单栏入口，负责启动服务和菜单 |
| `updater.py` | 自动更新逻辑 |
| `wifidrop.spec` | PyInstaller 打包配置 |
| `release.py` | 发布脚本 |

开发时调试：直接 `python3 server.py` 就有网页，不用打包。
