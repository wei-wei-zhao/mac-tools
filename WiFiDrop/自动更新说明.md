# 自动更新通道 —— 使用说明（给自己看）

## 现在是怎么工作的

**你的 Mac 就是更新服务器**，同事的 App 从你这台机器拉新版本。

```
同事的 WiFiDrop
      ↓ 每 6 小时查一次
http://TaldeMacBook-Air.local:8790/version.json
      ↓ 发现新版本，静默下载
自动替换 → 下次启动生效
```

之所以用**主机名**而不是 IP：公司 DHCP 4 小时续租一次，IP 会变（今天就从 `10.8.173.83` 变成了 `10.8.163.74`），主机名不受影响。

## ⚠️ 前提条件

| 条件 | 说明 |
|---|---|
| 你的 Mac 开着 | 关机/睡眠时同事更新不了（但推迟到下次能连上时） |
| WiFiDrop 在运行 | 更新服务是 App 的一部分，App 关了服务也停 |
| 同一个内网 | 同事必须和你连同一个公司网 |
| 网络不屏蔽 Bonjour | 少数企业网会屏蔽 `.local` 解析，这时会回退到 IP（但 IP 变了就失效） |

**如果你的 Mac 要长时间关机，同事只是不能更新，不影响正常使用。**

## 发新版本的完整流程

假设你要发 1.5.0：

```bash
cd /Users/tal/WorkBuddy/2026-10-28-11-06-49/wifidrop

# 1. 打包（自动写入版本号、预置更新地址、把更新包打进 App）
/Users/tal/.workbuddy/binaries/python/envs/default/bin/python release.py 1.5.0 \
  --local --notes "这次改了什么"
```

> `--local` 会自动取你的主机名，生成
> `http://TaldeMacBook-Air.local:8790/version.json`

```bash
# 2. 把新的 App 装到自己机器（这样更新服务才会共享新版）
mv /Applications/WiFiDrop.app ~/.Trash/
cp -R dist/WiFiDrop.app /Applications/
xattr -cr /Applications/WiFiDrop.app
codesign --force --deep --sign - /Applications/WiFiDrop.app
open -a /Applications/WiFiDrop.app
```

```bash
# 3. 把新的安装包也更新到桌面（发给还没装的人）
```

**完成。同事那边的 App 会在 6 小时内自动检测到，下次启动就变新版，你不用通知任何人。**

## 手动检查/触发

**同事端**：菜单 ⚡ →「检查更新」立即检查（不等 6 小时）

**自己端**：验证更新服务是否正常
```bash
curl --noproxy '*' http://TaldeMacBook-Air.local:8790/version.json
```

## 出问题了怎么排查

### 1. 更新服务没起来

```bash
# 看端口有没有监听
lsof -iTCP:8790 -sTCP:LISTEN

# 手动测
curl --noproxy '*' http://127.0.0.1:8790/version.json
```

如果没有输出，检查 `dist/release/version.json` 是否存在。

### 2. 同事那边查不到更新

先在同事电脑上确认能连你的机器：
```bash
curl http://TaldeMacBook-Air.local:8790/version.json
```

- **能连** → 是 App 的问题，看 `~/Library/Application Support/WiFiDrop/update_state.json`
- **连不上** → 网络问题。让同事改用 IP 试试：
  ```bash
  # 在你机器上看当前 IP
  ipconfig getifaddr en0
  ```
  然后让同事点菜单 ⚡ →「更新设置…」填 `http://<你的IP>:8790/version.json`

### 3. 代理导致失败（重要）

如果同事的 Mac 配了公司代理，访问内网地址会 502。
代码里已经处理：检测到 `10.x` / `192.168.x` / `.local` 等内网地址会**自动绕过代理**。

## 换一种分发方式（以后想改的话）

如果哪天你觉得「Mac 必须开着」太麻烦，换成别的源只需改地址：

| 方案 | 命令 |
|---|---|
| 内网文件服务器 | `release.py 1.5.0 --base-url http://files.company.com/wifidrop/` |
| 对象存储 | `release.py 1.5.0 --base-url https://xxx.cos.ap-guangzhou.myqcloud.com/wifidrop/` |
| 继续用本机 | `release.py 1.5.0 --local` |

然后把 `dist/release/` 里的 `version.json` 和 `WiFiDrop-x.x.x.zip` 传上去即可。

## 版本文件在哪

```
wifidrop/
├── updater.py                    # 更新逻辑（BUILTIN_UPDATE_URL 在这里）
├── release.py                    # 一键发布脚本
├── dist/
│   ├── WiFiDrop.app              # 打包产物
│   └── release/                  # 更新包目录（App 会自动共享这个目录）
│       ├── version.json
│       ├── WiFiDrop-1.4.4.zip
│       ├── 安装 WiFiDrop.command
│       └── 使用说明.txt
```

**注意**：`dist/release/` 里的内容会被打进 App，所以 App 有 68MB。
分发出去的 zip 是 41MB（含更新包）。
